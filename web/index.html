        Connect an AI agent

        Give Claude, Cursor or any MCP client the same sourced facts this site shows. The server runs on your machine, reads the published data and calls nothing else.

        1. 1. Get the data

          git clone https://github.com/OttObottr/airstack.git && cd airstack

        2. 2. Add it to your client

          Paste this into your client’s MCP settings, run from the cloned folder.

          {"mcpServers":{"airstack":{"command":"python","args":["-m","airstack.mcp_server","data/site"],"env":{"PYTHONPATH":"backend"}}}}

          Or start it by hand: PYTHONPATH=backend python -m airstack.mcp_server data/site

        3. 3. Ask

          Use AirStack to compare the sourced facts about two tools, with the page each one came from.
