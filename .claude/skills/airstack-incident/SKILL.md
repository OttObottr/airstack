# Incident

Verify the static site from a clean client and compare it with the released commit and manifest. Do not load-test, reveal request data, or change account controls from a public procedure. Hosted MCP is off by default.

If the issue is confirmed, record the affected surface and time, preserve private evidence, and follow the private operator record. Report only the user-visible outcome and recovery status publicly.
