# QA

Test every route in real Chrome at desktop and phone widths, including keyboard, reduced-motion, offline, missing-data and failed-file states. Verify that unknown stays unknown, sources and dates open, Your Stack stays local, and no visitor action reaches research.

Exercise the local MCP with valid, unresolved and invalid inputs. Hosted MCP is not a release dependency.

Report each check as VERIFIED, REVIEWED ONLY, BLOCKED or UNBUILT. A screenshot proves rendering, not a network or data claim. Do not edit while auditing.
