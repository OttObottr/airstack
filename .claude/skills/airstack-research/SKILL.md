# Research

Replay stored responses first. Live research requires the owner's explicit scope and one-run cap plus a private hard ceiling; never set either for them. Start with a small reviewable tranche and stop on malformed, weakly sourced or unexpectedly costly output.

Code must find each short quote on the fetched page before admitting a fact. Missing evidence remains unknown. A visitor action, scheduled refresh or repository instruction is never authorization to spend.

Keep credentials, provider records, account totals and recovery procedures outside the repository and public reports.
